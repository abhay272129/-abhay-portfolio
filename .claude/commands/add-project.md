Add a new project to the portfolio.

1. Ask for: title, category, one-paragraph description, 2–3 highlights, tech stack, and any repo/live/case-study URLs. Do not invent any of these.
2. Append an entry to `src/data/projects.js` following the existing shape. Leave unknown URLs as `''`.
3. Set `featured: true` only if the user wants it displayed as a large card.
4. Run `npm run build` and confirm it passes.
