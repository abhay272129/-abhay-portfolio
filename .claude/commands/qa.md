Run a quality pass on the portfolio.

1. `npm run build` — fix any errors.
2. `npm run lint` — fix real issues.
3. Review every file in `src/data/` against the authenticity rules in CLAUDE.md. Flag any invented metric, link, certification or job-seeking phrase.
4. Check responsive layouts at 360, 768, 1024 and 1440 px for overflow, spacing and type issues (use a browser if available).
5. Verify keyboard navigation, focus rings, mobile menu (open, Escape, link click), and reduced-motion behaviour.
6. Report findings as a short list, then fix what is clearly wrong.
