# Images

- `profile.webp` — professional photo (portrait, 800px wide, WebP ~40 KB). Referenced by `photo` in `src/data/site.js`.
  To replace it, export a portrait ~800px wide as WebP or JPEG (under ~150 KB) and update `photo`.
- `projects/` — real project screenshots (16:10, ~1600×1000, WebP/JPEG). Then set `image` in `src/data/projects.js`.
