## 2. Creative Direction and Visual Identity

Create a premium dark-themed portfolio inspired by the quality of sophisticated digital studios, modern product engineers' websites, and high-end editorial design.

The website should feel custom-designed rather than generated from a common portfolio template.

### Visual direction

- Deep charcoal and near-black backgrounds.
- Layered dark surfaces with subtle tonal variation.
- Restrained electric-lime or acid-green accents.
- Large, confident editorial typography.
- Strong visual hierarchy and generous whitespace.
- Thin borders and subtle separators.
- Carefully composed grids and asymmetrical layouts.
- Abstract 3D-inspired technical visuals.
- Refined hover states and smooth transitions.
- High-quality project cards with intentional image treatments.
- Subtle gradients, grain or texture only when they improve the design.

Use the accent color selectively. Avoid excessive neon, glowing borders everywhere, or a stereotypical cyberpunk aesthetic.

The result should feel elegant, technical, modern, and memorable.

### Typography

Use a carefully selected combination of:
- A modern sans-serif font for headings and body text.
- An optional monospaced font for technical labels, metadata, and code-inspired details.

Possible choices include Inter, Manrope, Geist, or another appropriate modern typeface.

Use a clear type scale, intentional line lengths, strong contrast, and fluid responsive typography.

### Visual references

Use these broad design principles as inspiration:
- Award-winning creative developer portfolios.
- Modern editorial websites.
- Premium product-design studios.
- Technical portfolios featuring abstract geometry and restrained motion.
- Contemporary dark interfaces with excellent typography.

Do not copy any specific website. Create an original design system.

## 6. Responsive Design

The website must be fully responsive, not simply a desktop layout compressed for mobile.

Support:
- Large desktop screens.
- Standard laptop screens.
- Tablets.
- Mobile phones.

Requirements:
- No horizontal overflow.
- Readable typography at all widths.
- Appropriate image and 3D visual scaling.
- Functional mobile navigation.
- Touch-friendly interactive elements.
- Responsive project grids.
- Consistent section spacing.
- Proper image aspect ratios.
- Smooth scrolling without navigation covering section headings.

Design mobile layouts intentionally. Reduce decorative motion and computationally expensive visual effects on smaller or less capable devices.

## 11. Implementation Workflow

Do not stop after producing a design concept, requirements document, or static mockup.

Execute the project in the following order.

**Step 1 — Inspect the environment**
- Inspect the existing files and framework.
- Preserve existing work if the project is already initialized.
- If the workspace is empty, create the React + Vite application.

**Step 2 — Establish the design system**
- Define color tokens, typography, spacing, borders, shadows, and animation conventions.
- Establish reusable layout components.
- Ensure the visual system is consistent across all sections.

**Step 3 — Implement the hero**
- Build the complete navigation and hero.
- Implement the abstract technical visual.
- Validate the initial viewport at desktop and mobile sizes.

**Step 4 — Implement the remaining sections**
- Build About, Experience, Expertise, Projects, Education, Learning, and Contact.
- Add responsive behavior and polished interactions.
- Keep content in reusable components and configuration files.

**Step 5 — Functional verification**
- Run the application.
- Check for build errors and console errors.
- Verify navigation, links, mobile menus, buttons, and form behavior.
- Test keyboard navigation and reduced-motion behavior.
- Verify the contact form only reports success when the service confirms successful submission.

**Step 6 — Visual refinement**
- Review the rendered website at desktop, tablet, and mobile sizes.
- Fix spacing, typography, overflow, contrast, alignment, and animation issues.
- Replace generic-looking sections with more distinctive compositions where needed.
- Remove decorative effects that reduce usability or performance.

**Step 7 — Handover**
Provide:
- A working implementation.
- A concise explanation of the architecture.
- Commands to install dependencies and run locally.
- Instructions for replacing the profile photo and project images.
- Instructions for updating projects, skills, and social links.
- Contact form configuration steps.
- Deployment instructions.
- A list of any remaining placeholders or unverified details.

If you have access to a terminal, browser, or development environment, use it to implement and verify the website rather than merely describing how to build it.

If a required tool or environment is unavailable, clearly state the limitation and provide the most complete usable implementation possible.

Before declaring the task complete, evaluate the website against these criteria:

1. Does it look like a premium, custom-designed personal website?
2. Does the hero establish a strong visual identity immediately?
3. Is the abstract visual implemented rather than left as a placeholder?
4. Is the typography excellent and the layout composition intentional?
5. Is the website responsive across desktop and mobile?
6. Are all sections complete and visually consistent?
7. Are projects, skills, education, and experience presented accurately?
8. Do all visible interactions work?
9. Is the code modular and maintainable?
10. Is the site lightweight and accessible?
11. Does the contact form work honestly, if included?
12. Can the website be deployed to free static hosting?
13. Does the finished website avoid looking like a generic template?

**Priority order:** visual quality and identity → content accuracy → responsive design → functional interactions → accessibility and performance → maintainability.

Use your professional judgment to make reasonable design decisions without asking unnecessary questions. Use placeholders for genuinely missing information, and keep them easy to replace.
